# Panduan Tangkapan Layar (Screenshots)

Simpan file tangkapan layar (screenshot) aplikasi dari emulator / perangkat fisik ke folder ini dengan penamaan berikut:

1. `01_all_notes.png`
   - **Kondisi:** Tampilan awal saat search field kosong.
   - **Tampilan:** Seluruh catatan tersimpan ditampilkan lengkap dengan tombol offline/sync.

2. `02_search_matched.png`
   - **Kondisi:** Tampilan saat memasukkan kata kunci pencarian yang cocok (misal: "belanja" atau "tugas").
   - **Tampilan:** Header menampilkan `Hasil pencarian (X)` dan hanya menampilkan kartu catatan yang judulnya cocok secara *case-insensitive*.

3. `03_search_empty_state.png`
   - **Kondisi:** Tampilan saat memasukkan kata kunci pencarian yang tidak ada di dalam daftar (misal: "zzz-tak-ada").
   - **Tampilan:** Menampilkan ikon `Icons.search_off` dan pesan `Tidak ada catatan dengan judul "zzz-tak-ada"`.
